# Parte 2 Laboratorio 1 - Conteo de ocurrencias con búsqueda lineal por cada elemento vs usar diccionario/hash (Opcion A).
El laboratorio consiste de dos partes dado que se ordeno hacer 2 ejercicios a eleccion de las opciones A, B, y C del laboratorio 1. 
El documento que especifica esto se encuentra en "Week 1 Intro/Lesson 1.1" en la pagina del curso.

Para recordar, el Laboratorio 1 tiene las siguientes opciones de ejercicios:
  A) Conteo de ocurrencias: (1) búsqueda lineal por cada elemento vs (2) usar diccionario/hash.
  B) Construcción de strings: (1) concatenación repetida vs (2) uso de builder/joins.
  C) Búsqueda: (1) lineal vs (2) binaria sobre datos ordenados (con preparación separada).
